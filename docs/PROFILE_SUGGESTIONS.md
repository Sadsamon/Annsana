Profile suggestions and quick checklist

1) Avatar & banner
- Use a high-contrast avatar (400x400 PNG) and a simple banner (1280x640) that matches your personal style or project branding.

2) One-line title
- Under your name, add a concise title: e.g. "Django developer • Open source • Cultural heritage".

3) Pinned repositories
- Pin 4 repositories that best showcase your skills:
  - Annsana — the main project
  - A tooling or library repo (if available)
  - A personal project that highlights UX or design
  - A notable contribution to someone else's repo

4) Profile README (what to include)
- Short banner or logo
- 2–3 sentence bio (who you are, what you build, what you're looking for)
- 3–4 bullet points: tech stack, focus areas, availability
- Featured projects with 1-line descriptions and links
- Contact details (email + other socials)

5) Repo topics and descriptions
- Add short descriptions to each pinned repo and 3–5 topics (eg: django, htmx, tailwind, cultural-heritage)

6) Visual polish
- Use consistent colors and the same avatar across GitHub, LinkedIn, Twitter
- Add social preview images for repositories you want to highlight

7) Ongoing actions
- Regularly update pinned repos and README with recent highlights
- Add CONTRIBUTING.md and LICENSE to important repos to encourage community involvement
